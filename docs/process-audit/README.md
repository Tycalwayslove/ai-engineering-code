# 流程审计

## 目的

- 保存 AI 工厂流程、协作方式和工作流稳定性的阶段性审计报告。
- 在进入功能开发前，先暴露流程、记忆、提示词、设计系统和质量门禁中的缺口。
- 为后续流程优化阶段提供待办清单和优先级。

## 边界

- 本目录记录流程审计结论，不替代 `ai-factory/` 下的工作流、记忆、提示词或 playbook 权威内容。
- 可从这里提出待完善点，但具体规则应回写到对应权威目录。
- 审计报告可以引用 Obsidian、飞书和 GitHub，但不把外部平台内容复制为第二份权威来源。

## 演进

- 每个关键阶段结束后，可新增一份审计报告。
- 当某个待完善点完成后，应更新对应流程资产，而不是只修改报告。
- 若审计发现架构级方向变化，应补充 ADR。
