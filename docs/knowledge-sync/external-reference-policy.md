# 外部引用规则

## 目的

定义外部资料、链接、文档、竞品观察和设计参考如何进入 AI 工厂流程。

## 默认流向

```text
外部引用
  -> intake 或 Obsidian
  -> 产品理解
  -> 需求点记录
  -> PRD / design brief
  -> durable memory 候选
```

## 规则

- 外部引用不能直接变成 durable memory。
- 外部引用不能直接变成开发任务。
- 重要引用应保留来源链接、获取日期和使用目的。
- 面试展示价值高的内容可以提炼到飞书。
- 竞品和设计参考必须区分事实、观察和推测。

## 记录建议

外部引用进入 `ai-factory/specs/intake/` 时，应包含：

- 来源。
- 日期。
- 摘要。
- 相关问题。
- 可能影响的需求或设计方向。
- 是否需要用户确认。

## 风险

- 资料过期。
- 误读来源。
- 将竞品实现当成自身需求。
- 将营销材料当成产品事实。
