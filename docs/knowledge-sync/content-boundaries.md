# 内容边界

## 目的

定义仓库、Obsidian、飞书和 AI factory memory 分别保存什么。

## 仓库

保存权威源稿和可验证资产：

- 代码。
- 契约。
- 规格。
- 工作流。
- prompt。
- playbook。
- memory。
- 飞书页面源稿。
- 流程审计报告。

## Obsidian

保存自由过程记录：

- 阶段成果。
- 临时判断。
- 个人理解。
- 工作过程。
- 对话总结。

## 飞书

保存展示型内容：

- 项目定位。
- 架构演进。
- 技术亮点。
- 面试讲解稿。
- 外部读者可理解的成果叙事。

## AI Factory Memory

保存结构化长期协作事实：

- 已确认产品原则。
- 架构事实。
- 设计原则。
- API 边界。
- 长期流程规则。

## 规则

- 飞书不是唯一权威来源。
- Obsidian 不要求严格结构化。
- durable memory 必须经过确认。
- 外部展示内容不复制所有内部细节。
