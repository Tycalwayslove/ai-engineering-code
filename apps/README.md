# Apps

## 目的

`apps/` 包含 AI 原生软件工厂面向用户的产品界面。

## 所有权

- `h5` 拥有移动优先的 Web 界面。
- `admin` 拥有运营管理 Web 界面。
- `ios` 和 `android` 是未来原生界面的占位边界。

## 依赖边界

- 应用可以依赖 `packages/` 下的共享包。
- 应用不得导入 `services/*` 或 `ai-factory/*`。
- 应用不得直接调用后端端点或实现自定义网络。
- 未来后端访问必须通过显式 SDK 或网关包流动。

## 演进

只有当契约和共享包所有权明确后，才添加应用专属能力。原生应用应来自真实产品需求，而不是占位脚手架。
