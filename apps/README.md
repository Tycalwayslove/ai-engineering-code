# Apps

## 目的

`apps/` 包含 AI 原生软件工厂面向用户的产品界面。

## 所有权

- `h5` 拥有移动优先的 Web 界面。
- `admin` 拥有运营管理 Web 界面。
- `ios` 拥有 iOS 原生壳、系统能力入口和 WebView 宿主。
- `android` 拥有 Android 原生壳、系统能力入口和 WebView 宿主。

## 依赖边界

- 应用可以依赖 `packages/` 下的共享包。
- 应用不得导入 `services/*` 或 `ai-factory/*`。
- 应用不得直接调用后端端点或实现自定义网络。
- 未来后端访问必须通过显式 SDK 或网关包流动。
- 原生壳不得承载产品业务编排；它只负责 WebView 容器、原生桥接、系统权限和宿主级交互。
- H5 不得假设自己运行在浏览器或原生壳中；宿主能力必须通过显式 Bridge 契约逐步接入。

## 演进

只有当契约和共享包所有权明确后，才添加应用专属能力。原生应用当前作为 Hybrid 宿主存在，后续仅在日历、通知、语音、相机、系统分享等明确需要设备能力时扩展。
