# conversation-service

## 目的

该边界定义会话和会话状态领域。

## 职责

- 拥有会话生命周期、会话状态和消息线程语义。
- 定义第一阶段中集中式 Python 后端使用的会话侧领域契约。
- 与 `api-gateway` 协调公共 HTTP 暴露，但不成为独立运行时。

## 非职责

- 第一阶段中不拥有独立运行时。
- 不拥有公共 HTTP API 形态。
- 不拥有持久记忆存储、画像记录或重复部署配置。

## 契约

- 拥有：未来添加到 `contracts/` 下的会话和会话状态领域契约。

## 拆分触发条件

- 出现独立扩缩容压力。
- 需要独立部署节奏。
- API 契约成熟且存在真实运营需求。

## 非触发条件

- 命名偏好。
- 推测性规模。
- 组织结构洁癖。
- 追求对称目录结构。
