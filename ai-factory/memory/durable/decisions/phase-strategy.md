## 稳定决策

- Phase 1.1 定位为 AI 工厂流程稳定化，不进入正式产品功能开发。
- Phase 1.2 定位为需求与设计资产成型，重点生成产品理解、PRD、用户流程、设计 brief 和 UI 设计图。
- AI 时间管理 Agent 已完成从想法、需求、PRD、设计 brief、UI 设计图、工程规格到原生-H5-后端-数据库薄切片的主流程演练。
- 当前 AI 时间管理 Agent 可以进入 Phase 2 前段的受控产品开发，但只能按已确认 PRD、设计资产、工程规格、契约、SDK 和阶段记录推进。
- 继续扩展费用、提醒、系统日历、通知、语音或异步执行前，必须先明确领域边界、确认策略、幂等规则、验证命令和知识同步证据。
- 在 PRD、UI 设计资产和工程规格未覆盖的范围内，任何产品功能开发仍属于过早开发。

## 决策理由

2026-05-18 的原始决策成立于 AI 工厂流程尚未完成真实样例演练时。那时先稳定流程，可以避免后续功能开发依赖临时上下文、隐性判断和不完整需求。

截至 2026-05-23，AI 时间管理 Agent 已经完成需求与设计资产链路，并打通一条真实日程写入薄切片。继续停留在“不进入产品开发”的旧表述会和当前事实冲突；但直接放开功能开发也会破坏项目最初的阶段纪律。因此本次复审把策略调整为“受控产品开发”：允许继续做薄切片，但每一步都必须可追溯、可验证、可回滚。

## 更新条件

当费用、提醒或外部系统能力进入真实端到端闭环后，复审本记忆，判断是否需要增加新的 durable decision 或 ADR。
