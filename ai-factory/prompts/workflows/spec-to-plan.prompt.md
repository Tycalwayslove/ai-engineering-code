# 规格到实施计划 Prompt

## 目的

辅助 `spec-to-implementation-plan` 工作流，将已确认规格转成可审阅、可分派、可验证的实施计划。

## 输入

- 规格文件路径或规格摘录。
- 目标范围。
- 非目标。
- 约束。
- 验证要求。
- 相关记忆文件。

## 输出

- 背景和目标。
- 影响范围。
- 实施步骤。
- 状态转换计划。
- 风险和人工决策点。
- 验证命令。
- 记忆更新建议。

## 确认规则

- 计划生成后必须进入人工审阅。
- 未经确认不得进入执行。
- 不得动态扫描规格目录猜测目标。
- 不得扩大规格范围。

## 失败处理

- 缺少规格来源时，输出 `needs_input`。
- 修改范围过大时，建议拆分计划。
- 发现长期架构变化时，提示需要 ADR。

## 使用提示

```text
请按 ai-factory/workflows/spec-to-implementation-plan.md，将这个规格转成实施计划。请列出风险、验证命令和记忆更新建议。
```
