# 产品理解 Prompt

## 目的

把用户的原始想法、外部引用和对话上下文整理为可确认的产品理解草案。

## 输入

- 原始想法或对话摘录。
- 外部引用路径或摘要。
- 已知阶段目标。
- 相关 working memory 或 durable memory 路径。

## 输出

- AI 当前理解。
- 已确认事实。
- 推测。
- 待确认问题。
- 推荐方案。
- 不应进入执行的提醒。

## 确认规则

- 输出后必须等待用户确认、补充或修正。
- 不得直接生成 PRD。
- 不得直接创建开发任务。
- 不得把推测写入 durable memory。

## 失败处理

- 输入来源不明确时，输出 `needs_input`。
- 想法范围过大时，建议拆成多个理解主题。
- 出现长期架构或技术路线判断时，提示可能需要 ADR。

## 使用提示

```text
请使用 product-understanding prompt，将以下原始想法整理成产品理解草案。请区分已确认事实、推测、待确认问题和推荐方案，等待我确认后再继续。
```
