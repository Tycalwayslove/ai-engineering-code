# 需求点记录 Prompt

## 目的

把已确认或待确认的产品理解拆成普通需求点记录。

## 输入

- 已确认产品理解。
- 用户补充意见。
- 相关外部引用。
- 需求点记录模板。

## 输出

- 需求点 id。
- 需求陈述。
- 来源。
- 优先级建议。
- 验收标准。
- 验证方式。
- 待确认问题。
- 是否需要设计输入。

## 确认规则

- 需求点不能直接变成开发任务。
- 未确认需求点状态必须是 `needs-confirmation`。
- 普通需求不得写入 ADR。
- 影响长期架构的需求应提示另行触发 ADR。

## 失败处理

- 缺少产品理解时，要求先运行 `idea-to-product-understanding`。
- 验收标准无法定义时，标记为 `needs-clarification`。
- 需求互相冲突时，列出冲突而不是自行裁决。

## 使用提示

```text
请使用 requirement-capture prompt，将以下已确认产品理解整理成需求点记录。不要生成 PRD，也不要生成开发任务。
```
