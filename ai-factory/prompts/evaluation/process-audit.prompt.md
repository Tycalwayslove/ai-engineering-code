# 流程审计 Prompt

## 目的

审计 AI 工厂流程资产是否足以支撑下一阶段工作。

## 输入

- 当前阶段目标。
- 仓库目录和关键文件。
- workflow、prompt、memory、playbook、contracts 状态。
- 已知风险或用户反馈。

## 输出

- 分块审计结果。
- 当前状态。
- 问题。
- 待完善点。
- P0/P1/P2 优先级。
- 是否允许进入下一阶段的建议。

## 确认规则

- 审计报告不能自动触发实施。
- P0 问题必须明确阻断原因。
- 不得把“目录存在”误判为“流程稳定”。

## 失败处理

- 证据不足时标记 `insufficient_evidence`。
- 发现架构级方向变化时提示需要 ADR。
- 发现流程过大时建议拆分。

## 使用提示

```text
请使用 process-audit prompt，按治理、规格、记忆、prompt、workflow、契约、运行时、设计系统、质量门禁、知识同步十块审计当前阶段。
```
