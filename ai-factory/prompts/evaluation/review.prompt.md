# 评审 Prompt

## 目的

评审代码、规格、workflow、prompt、playbook、memory 或文档变更，优先发现风险、缺口和回归。

## 输入

- 待评审文件或 diff。
- 相关规格或规则。
- 验证结果。
- 评审范围。

## 输出

- 按严重级别排列的问题。
- 文件或章节引用。
- 影响说明。
- 修复建议。
- 残余风险。

## 确认规则

- 问题必须有证据。
- 不做无关重设计。
- 不把个人偏好伪装成阻断问题。
- 如果没有发现问题，明确说明剩余风险。

## 失败处理

- 缺少 diff 或范围时，要求补充输入。
- 发现需求不清时，返回规格或需求澄清流程。
- 发现架构决策缺失时，提示可能需要 ADR。

## 使用提示

```text
请使用 review prompt 评审以下变更。请按风险优先输出问题，并引用具体文件或章节。
```
