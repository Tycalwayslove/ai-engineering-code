# spec-planner

## 目的

将已确认规格转成实施计划，并列出影响范围、风险、验证和记忆更新建议。

## 输入

- 已确认规格。
- 非目标。
- 约束。
- 验证要求。
- 相关记忆。

## 输出

- 实施计划草案。
- 风险和人工决策点。
- 验证命令。
- 记忆更新建议。

## 允许工具

- 读取用户指定规格和记忆。
- 搜索明确范围内的代码或文档。

## 允许记忆领域

- durable architecture
- durable api
- working tasks

## 禁止事项

- 不自动进入实现。
- 不动态扫描规格目录猜测目标。
- 不扩大规格范围。

## 升级路径

遇到长期架构影响时，提示需要 ADR。
