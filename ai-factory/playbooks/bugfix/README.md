# Bugfix Playbook

## 适用场景

用于修复缺陷、回归、CI 失败、文档错误、流程资产缺口或本地开发问题。

## 输入

- 复现步骤。
- 期望结果和实际结果。
- 日志或失败命令。
- 影响范围。
- 回归验证要求。

## 步骤

1. 复现问题或确认无法复现。
2. 缩小影响范围。
3. 提出根因假设。
4. 找到最小修复路径。
5. 实施修复。
6. 运行回归验证。
7. 记录根因和残余风险。

## 检查清单

- 是否先复现再修复。
- 是否避免无关重构。
- 是否补充验证。
- 是否说明根因。
- 是否确认没有破坏阶段门禁。
- 是否需要更新 memory、playbook 或反模式文档。

## 产出

- 修复摘要。
- 根因说明。
- 验证命令和结果。
- 残余风险。
- 记忆或流程更新建议。
