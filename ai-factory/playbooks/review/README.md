# Review Playbook

## 适用场景

用于评审代码、规格、工作流、提示词、playbook、memory、契约和知识同步变更。

## 输入

- 待评审文件或 diff。
- 相关规格、阶段门禁或约定。
- 验证结果。
- 评审范围。

## 步骤

1. 确认评审范围。
2. 查找对应权威来源。
3. 按严重级别列出问题。
4. 为每个问题给出证据、影响和建议。
5. 标记残余风险。
6. 判断是否阻断进入下一步。

## 检查清单

- 是否问题优先，而不是总结优先。
- 是否有文件或章节引用。
- 是否区分事实问题和推测风险。
- 是否避免无关重设计。
- 是否检查阶段门禁和权威来源。
- 是否说明未覆盖的风险。

## 产出

- P0/P1/P2/P3 问题列表。
- 修复建议。
- 残余风险。
- 是否通过评审的结论。
